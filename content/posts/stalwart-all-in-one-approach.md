[Stalwart: Can Open Source do Gmail-scale Email?](https://fosdem.org/2026/schedule/event/FP8EFX-scaling-email/) by [Mauro De Gennaro](https://fosdem.org/2026/schedule/speaker/mauro_de_gennaro/). >One server for your email, calendars, contacts and shared files, with spam and phishing protection built in. Every standard protocol your clients already speak (JMAP, IMAP, POP3, SMTP, CalDAV, CardDAV and WebDAV) supported natively.

## Installation and Basic Setup

I decide to make the a start the simplest possible configuration - All In One, base on PostgreSQL, with own managed IAM layer. For sure it's not production-ready configuration, in scenarios which I could imagine as target ones I need to build HA, separate identity layer and so on. But somehow it's need to get some basic experience. AAlso at start it's deployed without expose on internet access.
